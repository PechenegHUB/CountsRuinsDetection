# Зависимости

Базовые утилиты используют стандартную библиотеку Python. cached.txt дословно перенесён из final/requirements.txt закреплённого коммита; это окружение исходной CPU-сборки, а не инференса нейросетей. Устанавливайте его в отдельный Python3.10 venv. Зафиксированного проверенного training/GPU-окружения нового проекта пока нет.
