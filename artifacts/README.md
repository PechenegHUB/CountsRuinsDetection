# Локальные артефакты

Рекомендуемые подпапки: `bundles/`, `weights/`, `legacy/`, `cache/`, `runs/`.

- bundles: отдельно полученные архивы CPU-входов и весов;
- weights: распакованные checkpoint по manifests/weights.json;
- legacy: закреплённый исходный репозиторий для CPU-сборки;
- cache: пересоздаваемые признаки и боксы;
- runs: выходные CSV и журналы.

Всё содержимое игнорируется Git, кроме этого README. Сама папка не означает наличие артефактов.
