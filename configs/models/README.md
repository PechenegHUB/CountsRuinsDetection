# Конфигурации моделей

Точные опубликованные нейросетевые файлы: ../../manifests/weights.json.
Зафиксированные YOLOE prompts, thresholds и inference settings: ../../manifests/yoloe.json.

Единый загрузчик моделей ещё не перенесён. Здесь не создаются выдуманные рабочие YAML. При переносе у каждого конфига должны быть версия upstream-кода, препроцессинг, checkpoint SHA и проверка загрузки параметров.
