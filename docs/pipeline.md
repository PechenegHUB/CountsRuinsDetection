# Пайплайн D53

Документ описывает зафиксированное исходное решение, а не заявляет готовый перенос всех моделей.

## Происхождение столбцов

- **people:** EXP-044 student, медиана целевого кадра и двух соседей, порог/масштаб исходного рецепта, затем округление.
- **hands:** student по целевому кадру, ограничение `2 × people`, округление.
- **dishes:** student с медианой трёх кадров и округлением. YOLOE-dishes не подменяет этот финальный столбец.
- **items:** EXP-032 (`25% EXP-016 +75% clean D-FINE-X`), D4 добавляет половину положительного разрыва при clean≥2; D42 проверяет отдельный слабый Book/Cell Phone; D48 может добавить ещё1 при достаточном числе разных боксов.
- **cups:** базовый столбец, унаследованный student pure от upstream CSV; D6 объединяет production, student, teacher и YOLOE; D14 проверяет кропы; D21 использует временные подтверждения, D45 корректирует согласованные случаи на ±1.
- **occ_prob:** базовая вероятность upstream, затем D50 меняет odds в зависимости от наличия людей.

`student_submit.py` заменяет в base CSV только people/hands/dishes. Поэтому выражение «CSV ученика» не означает, что все шесть полей получены нейросетью-учеником.

## Сборка

Эталонная цепочка: D4 → D21 → округлённый D21 → D42 → D48 → D53. D53 использует cups D45, items D48 и поправку занятости D50. По исходному отчёту относительно D42 изменены cups на2 строках, items на22 и occ_prob на4733; people/hands/dishes сохранены.
