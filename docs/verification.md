# Проверка нового репозитория

Дата: 15 ноября 2026.

- 11 автоматических тестов прошли на Python 3.13.1: формат CSV, диапазоны, дубли, AP со связками, крайние случаи, SHA, защита путей и вызов закреплённого кода на синтетическом примере.
- CLI запускается без импорта PyTorch и Transformers.
- Все семь файлов архива весов проверены по SHA-256 и размеру.
- Вложенный `final_d53_cpu_inputs.zip` из `D53_jury_run.zip` совпал с эталонным SHA-256; проверка целостности ZIP прошла. Недостающий в старом архиве файл `d41/embeddings_cuda.npz` присутствует.

Полный реальный D53 новым запускателем пока не прогонялся. Синтетический тест не подтверждает нейросетевой инференс, обучение или совпадение финального CSV. Результаты D53 в README взяты из закреплённого исходного проекта. Python 3.10 с исходным CPU-окружением здесь ещё не проверен.

Метрика дополнительно сравнена с исходным score.py организаторов на 100 синтетических наборах, включая одинаковые вероятности, нулевые классы и Ignored. Максимальное расхождение: 2.22e-16.

Пакет wheel успешно собран и установлен в отдельный локальный каталог без зависимостей. CLI установленного пакета запускается.
