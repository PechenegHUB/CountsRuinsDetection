# История решений, вошедших в D53

Новый репозиторий не копирует весь исследовательский архив по папкам участников. Полный журнал сохранён в [исходном проекте](https://github.com/PechenegHUB/Counts_ruins/blob/00b6fb3188f72ddebe1e297cf0e3ea6e0c5c67e2/EXPERIMENTS.md).

- EXP-016: Ridge с DINOv2/детекторными признаками и YOLOE.
- EXP-023/032: clean D-FINE-X и смесь items с EXP-016.
- EXP-044: обученный ученик D-FINE-L для пяти классов.
- D4: поправка множественности items при нескольких clean-предложениях.
- D14/D21: проверка чашек и временное подтверждение.
- D42/D48: слабые предложения вещей и добавление ещё одного предмета.
- D45/D50: согласование чашек и ранжирование занятости.
- D53: зафиксированная финальная композиция.

Обозначения сохранены для трассировки, но новые модули должны называться по выполняемой функции. Исследовательский код и изменения, не вошедшие в финальную композицию, не следует подключать автоматически.
