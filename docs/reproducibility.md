# Воспроизводимость

Основной запуск `run.py` использует компактный код из переданного командой архива `D53_solution.zip`. Дополнительное скачивание исследовательского репозитория не требуется. Происхождение записано в `manifests/compact_source.json`.

`prepare_heads.py` отдельно обучает три логистические головы и сохраняет коэффициенты и пороги. `run.py` загружает эти параметры из `models/heads.json`. При предсказании обучающие метки и ручные аннотации не используются.

Тяжёлые нейросетевые выходы и признаки берутся из `final_d53_cpu_inputs.zip`. Это режим работы по сохранённым выходам, а не инференс нейросетей на новых JPEG. Базовые счётчики и исходная вероятность занятости также поступают из архива.

Проверки входного архива и промежуточных CSV сохранены внутри программы. Эталонные суммы находятся в `manifests/reference_compact.json`. Результат сохраняется как `submission.csv`.

Старый CLI `reproduce-cached` оставлен для проверки исходного варианта и использует закреплённый исследовательский репозиторий. Основная инструкция README использует новый `run.py`.
