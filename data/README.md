# Локальные данные

Распакуйте пакет организаторов в `data/organizer/`, сохранив CSV, изображения и вспомогательные `.py`. В `--data` передаётся папка с `sample_submission.csv`.

Содержимое data/ игнорируется Git, кроме этого README. Никаких учебных примеров или изображений в репозиторий не добавлено. Состав материалов — [ASSETS_REQUIRED.md](../ASSETS_REQUIRED.md).
