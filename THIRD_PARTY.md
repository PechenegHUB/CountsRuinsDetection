# Происхождение компонентов

Это перечень источников и заявленных upstream-условий, а не назначение одной общей лицензии всем артефактам.

| Компонент | Источник / условия из исходного проекта |
|---|---|
| D-FINE | https://github.com/Peterande/D-FINE ; код Apache-2.0. Отдельная лицензия использованных Objects365 checkpoint в источнике не указана; не приписываем им автоматически лицензию кода. |
| YOLOE-26m-seg и MobileCLIP | Ultralytics; YOLOE отмечен как AGPL-3.0 в финальном манифесте. Точные assets/версии/хэши в manifests/yoloe.json. |
| DINOv2 Small | https://huggingface.co/facebook/dinov2-small ; Apache-2.0. Ревизия ed25f3a31f01632728cabb09d1542f84ab7b0056. |
| EXP-044 student | Получен командой дообучением D-FINE-L; точный checkpoint указан в manifests/weights.json. |
| Данные и scorer | Исходный пакет организаторов Case2; изображения и аннотации не распространяются этим репозиторием. |
| Эталонный код D53 | https://github.com/PechenegHUB/Counts_ruins/tree/00b6fb3188f72ddebe1e297cf0e3ea6e0c5c67e2 ; вызывается через отдельный checkout, не объявляется заново реализованным здесь. |

Нейросетевые веса, изображения и кэши не включены. Для каждого получаемого архива необходимо сохранить происхождение и сверить SHA. Подробные пути и манифесты — в [списке материалов](ASSETS_REQUIRED.md).

Компактные модули `src/countsruins/pipeline/` происходят из переданного командой `D53_solution.zip`; хэш архива указан в `manifests/compact_source.json`. При переносе разделены подготовка голов и предсказание.
