# Скрипты

`reproduce_cached.py` — дополнительный вход в тот же проверяющий запускатель, что `python -m countsruins reproduce-cached`. Сначала установите пакет.

Скрипты обучения, подготовки псевдометок и полного инференса появятся после переноса и проверки. Пустые `train.py`/`predict.py`, создающие впечатление готовой реализации, не добавлены.
